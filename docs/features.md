# 핵심 기능 명세 및 비즈니스 로직 가이드 (features.md)

이 문서는 G-Club 웹 애플리케이션의 핵심 비즈니스 로직과 기능 명세를 상세히 정리한 문서입니다. 이를 통해 서비스 기획 및 핵심 알고리즘 수정 시 혼란을 방지하고 일관된 동작을 보장합니다.

---

## 🎮 1. 게임 메이트 구하기 (Game Mate)

동아리원들이 같이 게임을 플레이할 동료(메이트)를 구하는 매칭 게시판입니다.

### 1.1 실시간 상태 업데이트
* **구현 방식**: Supabase Realtime을 적용하여 메이트 모집글이 등록되거나 상태가 변경되면 클라이언트에 즉시 상태가 동기화됩니다.

### 1.2 모집글 자동 만료 (상태 변화 스케줄러)
* **비즈니스 규칙**: 
  * 메이트 모집글에는 **게임 시작 시간**이 명시되어 있습니다.
  * 예약된 게임 시작 시간이 현재 시간 대비 일정 시간 경과하면, 수동으로 닫지 않아도 해당 글의 모집 상태가 자동으로 **'완료(Completed)'** 또는 **'만료(Expired)'** 상태로 강제 전환됩니다.
  * 이는 DB 크론(cron) 또는 API 요청 트랜잭션 수립 시 서버 단에서 확인 후 자동으로 처리합니다.

## 🔨 2. 대회용 팀 경매 시스템 (Auction Board)

동아리 내전 혹은 공식 대회 진행 시 팀장들이 포인트(가상 화폐)를 이용하여 팀원을 입찰, 팀을 선발하는 경매 시스템입니다. (`AuctionBoard.tsx` 참조)

### 2.1 사용자 역할 권한 매핑 (중요)
사용자가 접속하면 아래 우선순위에 의해 역할(`activeRole`)이 부여됩니다.
1. **팀장 여부 (`isLeader = true`)**: `CAPTAIN` 역할 부여 (입찰 가능)
2. **시스템 관리자 여부 (`isAdmin = true`)**: `ADMIN` 역할 부여 (경매 제어 가능)
3. **일반 시청자**: `VIEWER` 역할 부여 (실시간 대시보드 관전만 가능)
> [!IMPORTANT]
> **권한 매핑 예외 규칙**: 만약 한 사용자가 시스템 관리자(`isAdmin`)이면서 동시에 팀장(`isLeader`)인 경우, **팀장(`CAPTAIN`) 권한을 최우선으로 부여**하고 관리자 조작 컨트롤은 화면에서 숨깁니다.

### 2.2 파산 방지 입찰 상한액 산출 공식
경매 시스템은 팀장이 보유 포인트를 다 소진하여 남은 팀원 자리를 채우지 못하는 상황(파산)을 방지하기 위해 **입찰 가능한 상한선(`maxAllowedBid`)**을 실시간으로 제한합니다.
* **공식**:
  $$\text{remainingSlots} = (\text{maxTeamSize} - 1) - \text{team.members.length}$$
  $$\text{slotsToKeep} = \max(0, \text{remainingSlots} - 1)$$
  $$\text{maxAllowedBid} = \text{team.currentPoints} - (\text{slotsToKeep} \times \text{minBidIncrement})$$
* **설명**: 
  * 내가 데려와야 하는 남은 인원 수에서 가장 저렴하게 영입할 수 있는 최소 비용(최소 입찰단위 `minBidIncrement`)만큼의 보증금을 묶어둔 뒤, 남은 금액으로만 현재 매물에 최고가 베팅을 할 수 있도록 방어 장치를 제공합니다.

### 2.3 실시간 입찰 통신
* 입찰 요청은 서버 액션(`placeBid`)을 통해 트랜잭션으로 처리하며, 유효성 검사 성공 시 Supabase PostgreSQL DB에 로그를 기록하고, 즉시 Supabase Realtime 채널을 통해 모든 클라이언트에 입찰 내역(`bids`) 및 잔여 시간 타이머 연장 여부를 전파합니다.

## 📢 3. 공지사항 (Notices)

동아리 전체 공지 및 게시글 작성 공간입니다.

* **에디터 탑재**: `Tiptap` 라이브러리를 활용하여 이미지 임베드, 링크, 유튜브 임베드 및 이미지 리사이징 기능이 포함된 리치 텍스트 에디터 환경을 제공합니다.
* **이미지 첨부 및 삭제**: 
  * 공지사항 작성 시 삽입하는 이미지는 Supabase Storage 버킷에 저장됩니다.
  * **버킷 연동 제거 시 처리 규칙**: 게시글이 삭제되면 해당 게시글에 매핑되어 저장되어 있던 Storage 내 이미지 파일들도 가비지 리소스로 남지 않도록 함께 제거 처리를 진행해야 합니다.

## 📅 4. 캘린더 일정 관리 (Calendar)

동아리 스케줄(정기 모임, 내전 일정, 대회 일정)을 한눈에 확인할 수 있는 일정 관리 보드입니다.
* `react-big-calendar` 모듈을 도입하여 월(Month), 주(Week), 일(Day), 목록(Agenda) 단위 조회를 제공합니다.
* 모바일 환경에서는 캘린더 화면이 축소되지 않고 잘 보일 수 있도록 폰트 크기 강제 축소 및 패딩 오버라이드(`.calendar-full-width-mobile`) 반응형 스타일을 적용했습니다.
